# learning-landed — the file is already there, and nothing asked

Why: the gate before a write reads shapes, and a shape list is silent on the route nobody thought of.
This one reads the disk instead, so a memory or a skill file that appeared unasked is answered for.

How to clear it: say in one line which of the five conditions the file meets. If none holds, remove
it: this fires after the write, and a file kept because deleting it felt wasteful is what the five
conditions are against.

How to avoid it: write a memory with `Write` and a skill's text with `Edit`, where the question comes
first and is stamped, so it is never asked twice.

What it sees: a guarded file changed in the last two minutes — one a command named, and any in this
session's memory directory or the repository's skill directories. A tracked file the tree agrees with
was restamped, not written. What is left can be somebody else's edit, or a file the call only read
while something else restamped it: say which, and it is not asked again.

Not judged: whether the fact is true or useful; a file outside `memory/` or `skills/`; an installed
copy of this plugin, where the host's install record places one — an update rewrites it whole, so
no run records learning there.

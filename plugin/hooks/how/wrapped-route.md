# wrapped-route — an action a verb wraps is asked for by its verb

Why: the tracker's tool reaches every write and takes none of the reading a verb takes — no kind
required, no fold onto a neighbour, no rank written, no key in the reply. Two routes to one write is
a second copy of every rule, and the copy is the one with no rules.

How to clear it: type the verb the refusal names. It makes the same call and adds the reading this
route skips. Where the verb is withheld or gated for this credential the refusal says so instead:
the withholding is the decision, and the raw action is not what is left when the verb goes.

How to work through it: the pairs are read off the same table the capability gates are keyed on, so
there is no list of refused actions to consult and no second place for one to go stale.

Not judged: an action no verb is the route to — a description updated in place, a transition the
flow does not own, the mark a ship writes, a read a verb only spends on its way elsewhere. Silent
with no endpoint configured, the verb named being this CLI's.

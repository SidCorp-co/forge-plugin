# restart-owed — a file an open session cannot pick up

Why: the registration a session read at start is frozen until it restarts, so this text reaches
nobody until somebody restarts. Most of what landed there had a live home: a rule under `plugin/src/`
that the CLI serves per call, or a sentence a guide already carried.

How to clear it: say in one line why no live home fits, then re-send. The line is kept, and the
release step prints it beside the file, so a file that moved for no stated reason is visible there.

The live homes: a rule with a checker under `plugin/src/`, loaded fresh per call; method text in a
guide, served by `forge guide`; a gate's reasoning on a page like this, served by `--how`.

The set is not this tree's directories: it is the registration, the thin entries it names and their
static graph, the stubs and the roles. A gate, a harness line and a page like this one already reach
an open session, so none of them is held.

Asked once per file per session; a second write passes.

The shell route counts a write shape beside the name; reading one is not writing it, and a path in
a sentence is prose. A write outside a checkout of this plugin is nothing to hold.

Not judged: whether the reason is a good one. The gate asks for the line and records it.

# brief — a dispatch message nobody generated

Why: a typed message carries what the dispatcher believed about the method, and a run reads it
first. On 2026-09-23 five briefs carried a rebase order under text forbidding it (ISS-2148).

What to do: send what `forge brief ISS-nn --tree <the run's worktree>` prints (no `--tree` for a
run given none), whole and unchanged; a judge's or a requirement's form: `forge brief -h`.

It teaches, never refuses: the dispatch goes as written and the brief to send arrives beside it,
which brief being a way of working, not kernel input. What it judges: whether the whole prompt is
one the verb printed in the last ten minutes, and for the judging role whether it is the judge's
form, naming a deployment or a program and, but for a program judge, no tree (ISS-3145).

Said only where the tracker gates the project `strict`, or fast delivery is off; read per dispatch,
a failed read keeps it. `forge doctor` prints the `gates` row.

Not judged: a role another plugin ships, and a general agent. A digest of the whole is compared,
never words (ISS-2147).

## Naming a cause

Three grades. The account carries every one of them that is true when it is written, and a run that
has all three says all three.

- **Confirmed cause.** The evidence rules the alternatives out, and you can say which evidence and
  which alternatives. Anything less is the grade below.
- **Leading hypothesis.** The evidence favours one candidate without eliminating the others. Name the
  candidate, name the nearest rival, and name the one observation that would separate them. A leading
  hypothesis with no separating observation attached is a confirmed cause wearing a softer word.
- **Unresolved uncertainty.** Something you looked at and could not settle. It goes in the account
  even when the release succeeded, because the next run inherits it.

Where two candidates are supported equally, say exactly that and stop; inventing the tiebreak is the
failure this grading exists to prevent, and it is the moment a run is most likely to do it. Equal
weight between causes is also one of the conditions that hands the release over.

Never write `root cause`. It reads as confirmed however thin the evidence behind it was, it survives
into every summary that quotes the account, and it is the phrase a reader trusts most and should
trust least. Use the grade the evidence earned.

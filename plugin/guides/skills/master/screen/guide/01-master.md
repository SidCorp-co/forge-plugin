# Master: which command answers the question a pass is asking

A master builds in batches where its project runs direct, and dispatches waves where it does not.
Neither method maps this CLI; this page does: a question a pass asks, and the command that answers
it. It rules on nothing, so what to do with an answer is the method's and what a status is owed is
the contract's. It names no flag, because every verb describes itself in the copy that answers
it: `forge <verb> -h`.

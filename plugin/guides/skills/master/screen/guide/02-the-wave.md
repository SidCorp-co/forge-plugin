## The wave

- What this wave should take, and why in that order: `forge next`.
- What is finished and nobody is judging: `forge next`, whose judging lane lists the landed rows a
  judging run has yet to claim, above the ranked list, wherever the project made that judgement an
  independent run's.
- Why a candidate was left out: `forge next`, which gives each row's reasons on request.
- What blocks what: `forge next`, which prints the edges it read in place of the ranking on request.
- Whether an issue is already open twice: `forge alike`.
- What a run cannot read for itself, which is the message a dispatch sends: `forge brief`.
- Where a wave stands: `forge resume`, read on the wave's headline.

# Master: which command answers the question a pass is asking

A master runs its waves by the dispatch method, which says what to do and carries no map of this
CLI. This page is that map: a question a pass asks, and the command that answers it. It routes and
it rules on nothing, so what to do with an answer is the method's and what a status is owed is the
contract's. It names no flag either, because every verb describes itself in the copy that answers
it: `forge <verb> -h`.

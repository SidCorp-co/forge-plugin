## Phase 2 — Decide; ask only under condition 2

Take the reading that is cheaper to reverse, write it up in the shape `forge record decision -h`
takes, and carry on. This is the default even for a choice expensive to reverse — a package boundary,
a wire format, a decision others are made against: decide it and record the decision on the item it
shapes. The tracker refuses a person a question the run may decide itself off a `strict` project
(`QUESTION_AGENT_DECIDES`), so a question is the exception, not the way out of a hard call.

**The decision record names the goal it serves**, one of the identifiers Phase 0 read off the brief
or a clause this project's tree resolves, the way `complexity` names a rung. That is what separates a
fix of the cause from a fix of the surface at the moment the choice is made rather than in a review
of fifty issues afterwards, and a run that keeps writing *none stated* is telling whoever reads the
backlog something about the brief.

When you must ask, the readings go up in the shape `forge record question -h` takes, so whoever
answers chooses between visible results rather than between readings; then park it with kind
`question` and move to the next issue. By default the question is addressed to the master
(`--to master`, `blockerKind: master_or_peer`), which is taken on any project. A person is asked only
where this project is `strict` **and** the decision is serious — it cannot be undone, spends real
money, touches credentials, or sets product direction — in which case the question carries
`--serious`. Off `strict`, or for a decision that is not serious, the tracker refuses a person's
question (`QUESTION_AGENT_DECIDES`): decide and record it, or ask the master. What the decision
record earns is read with the rest of `approved` at Phase 3.

**A credential Phase 0 found missing is asked for here**, once Phase 1's claim is taken, and never
at Phase 7. It is the question record alone and not the park, and it is addressed to the master
(`--to master`) off a `strict` project, since only a person at the master's box holds the secret.
What stands as evidence while the answer is outstanding is Phase 5's question, and the verification
reference it reads answers it.

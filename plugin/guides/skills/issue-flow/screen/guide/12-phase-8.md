## Phase 8 — Clean up, and consider whether anything was learned

Clean up as soon as the evidence is captured. **The mechanical half of it is one call where the
project has one** — the workspace this run made and what it left running, ended by the same script
Phase 0 read the steps around a change off. Take that call rather than a list of steps: a run
deciding for itself what in a directory two runs share counts as its own is how one run's scratch
outlives it and another's gets taken with it, and a verb that knows the name it created can only
remove what it made. Where the brief names no such call it is by hand — temporary servers, data and
scratch files go, and the user's stack is confirmed still answering. Either way a workspace holding
work no record cites is left standing and said to be, never forced, and what outlives the run is what
a verdict cites, attached where the verdict is.

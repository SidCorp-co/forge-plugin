### `in_progress` — reads the plan, the baseline and the branch

Capture the branch before the move. The hours go into a tree, and only what is written outlives the
shell that held it.

Take one read of the whole set of files the change touched, at the head the landing will use. That is
the pass the review is earned by, and it is the last step before the criteria are judged — never a
recheck, which answers findings, and a clean pass leaves none. Post a correction for a file the plan
does not name before writing it. Scope does not grow in silence.

### `confirmed` — reads the confirmation and the code behind it

This status promises that somebody read the code. Leave it by deciding every ambiguity or by saying
*none found*. Ask a person about one that is expensive to reverse. A rung drops payloads, never the
right to ask.

The next status promises *object to the plan now, not after*, so the plan and the criteria are
written here too, before the code, and a second reader reads them before the issue takes them. Never
relax a criterion to match what got built; correct it in the open instead. A correction that re-sizes
the work climbs a rung and never comes back down: the complexity is the reporter's claim, and what
the work turned out to be is the run's.

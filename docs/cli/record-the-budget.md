# `record` — the budget

**A field's budget is printed before it is spent, and measured before it is sent.** Core screens
every field of a record block at 400 code points (`field-budget`) and refuses a record carrying a
longer value whole; a run learned the number only by failing, and 9 of 250 `forge record` calls in
the Agenfold sessions of 2026-10-30/31 came back over it. So each kind's `-h` prints the budget
beside every free-text field it caps, and a value over it — a repeated field measured value by value
— is refused here, naming the flag, its length and the budget, before any request. The release
note's title is held the same way to core's own bound, 80 characters and 10 words, and a written
note with no title is owed before `awaiting_release` rather than met as core's refusal there.
`comment` and `issue` print the caps their writes are measured against from the same table.

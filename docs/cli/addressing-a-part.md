# A part is reached by an address

[The parts](the-parts.md) is the other half: what one project's own answers take out of a part
before it arrives. This page is how a part is reached at all: the address a reader types.

## A phase is addressed by its number

The parts of a text are its own headings, which is already how the contract is cut, and a phase
heading's key is the number the reader is already holding: `forge guide harness-eval 2` is the Phase 2
part. Nothing keeps a second index in agreement with the headings, and renaming a heading moves the
call that reaches it the way it does in the contract. A reference keeps its name, so the citations
the method makes of its own references go on resolving beside the numbers.

The number addresses the whole phase, subordinate headings included. Cutting a text at its headings
ends a part at the next heading of *any* level, so a phase that grows a subsection would answer its
number with the half above that subsection and say nothing about the rest — a part of the method
unreachable through the only address it has. So a phase gathers every heading beneath its own level
until the next one at that level or above.

A part ends by naming the flow it was rendered for, and it names one: every part a reader is served
comes out of that flow's own directory, so there is no second flow a part could have come from. A
phase read for a flow nobody named cannot be held against the flow the project runs, and that
comparison is the whole reason a project names one. The corpus reads that line back rather than this
copy's own key, so a transcript is a fact about the run that made it; the retired `Method version 1`
line reads as flow `default`, which is the retirement's own precedence applied to a read.

## The verb that acts carries no phase

`forge claim`, a record write and the ship's last step each printed the issue-flow phase their act was
in, until that method became core's served page (ISS-69). A phase cut out of core's page by a number
this copy keeps would be a second index over a text this copy does not own, going stale the first time
core renumbers its steps, so nothing is carried: `forge resume` and the lane name the phase owed, and
the method is read whole at `forge guide issue-flow`.

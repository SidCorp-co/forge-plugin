# ChatGPT — asking for a picture

An image ask is its own action because what it requires of a caller is what it exists to state. Both
requirements are refused before anything is sent, and neither is defaulted: a default aspect ratio is
the square picture nobody asked for, arriving with no sign that a choice was made for them. The
refusal names both whichever one is missing, since a caller told about one, who fixes it and then
meets the other, has spent two rounds learning one shape.

The framing is saved and never typed. It is the part that drifts — style, medium, what to leave out —
and a value re-derived per call comes back different every time, which is what makes three pictures
for one deck look like three pictures for three decks. So it sits in this plugin's own configuration
beside the endpoint and the key, written by the diagnostic verb and reported by it, and there is no
flag beside it: a flag would be a second spelling with a precedence rule to explain, and a value
typed per call is the very thing being closed.

The aspect ratio travels inside the prompt, because there is nowhere else for it to go. The backend's
tool takes a prompt, a model, a conversation id and a list of files, and nothing else, so the only
question left is which words the model will not read past. It is sent as the last line, alone, as an
instruction rather than a wish. What is on record for that wording is narrower than the reason it was
chosen: on 2026-09-12, against `gpt-5-6`, 16:9, 9:16 and 1:1 each came back at the shape asked for —
and so did a control that buried `in a 16:9 aspect ratio` in the middle of a sentence. So the isolated
line is not what rescues a ratio on this backend today; what this action buys, and what the pictures
prove, is that no call goes out without one. The wording is the cheap half of that and is kept because
a model that starts reading past a clause in prose is found by looking at a picture, never by a red
gate.

The prompt is written short, and the help says so in the row a caller reads. A generation model
elaborates a short prompt and transcribes a long one, so four hundred words specifying every element
buy a literal reading of those words rather than the thing they gesture at. The rule belongs in the
help text because the caller holding this CLI is usually an agent, and an agent with room to write
will use it.

A run of pictures shares one conversation, which needs no mechanism: every reply already prints the
id that continues it, and the line an image turn prints continues it as an image, at the ratio this
call asked for. A detached picture carries the same, because the child is spawned under the action
that asked for it rather than under a fixed one.

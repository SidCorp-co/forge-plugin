# Vietnamese

`vi-natural review` was tried as the gate and cannot be one: it flagged its own previous suggestion, so
it has no fixed point and blocking on its findings never terminates. Translating is one deterministic
pass, and a source that stays English is the source to fix. The binary is the one shipped beside the
plugin, never whatever PATH resolves — a plugin that spawns a copy it did not ship has no idea which
contract it is getting.

A refusal from this boundary carries the command that writes the text. `vi-natural` says how a
gateway is configured, which is not what a run needs next: it needs the one verb that produces the
Vietnamese, and it used to go and read `vi-natural -h` to find it — forty times in three days on one
project. The line is built from the argv the wrapper is about to spawn, so a hand-written second copy
of it cannot exist to go stale, and the file pair `doc` is given is shown as placeholders because the
temporary one is gone by the time anyone reads the refusal.

A release note is the one prose field that is an object rather than a string, so the layer walks a
path to the half that is prose. `section` is an enum a reader keys on and `technical` is the payload
half a run cites; both are stored as written, and only the user-facing half is rewritten — by `doc`,
the verb a description goes through, because the Outcome is that a note is treated as one. Its
read-back compares each half against the copy that went out and normalises nothing: the tracker
stores all three byte for byte, unfenced and untrimmed, and a comparator that forgave a difference
would stop saying the write landed. A withheld note's reason sits in the user-facing half and is
rewritten with it — the tracker is Vietnamese and it is the tracker that holds it.

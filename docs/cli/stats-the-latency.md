# `stats` — a class's seconds a call, and the bound that names one

## Why a class's seconds a call is in the comparison, and what its bound is not

A waiting share is one number over every class at once, so a fortnight in which the second model
doubled its answer time and a fortnight in which the harness needed more rounds read the same, and
the change that separates the two windows takes the blame either way. The seconds a call each class
took is the figure that tells those apart, and it costs nothing to take: the profile already folds
every call into `byClass` in the pass that builds it, so both windows carry it before the comparison
asks.

**A class's denominator is what it did and what a run looked up, and the mixture is printed rather
than removed.** The classifier files `forge record verdict -h` under the row `forge record verdict`
on purpose — a lookup of a verb's help belongs to that verb — so a class's calls are uses and
lookups together, at roughly one in nine over this corpus. Taking the lookups out of the count would
leave their wait in the sum and understate nothing but the arithmetic; so both sides print the count,
and a window whose runs had to look something up more often is visible as that rather than as a verb
that got slower.

**The bound that decides which class is named is a constant and not a floor measured off the
corpus.** An angle's floor is a pass of block profiles for one named scalar figure, and it is
computed beside the reading precisely so that the release step's mark writer never spends it; the
class set, unlike the angle set, is whatever the corpus classed, so a floor here would be that pass
once per class, inside the one assembly both mark writers store. The constant is stated on the screen
for the same reason the floors are: a reader who cannot see what named a class cannot judge the
naming.

**The minutes beside a named class are tool-minutes and say so.** A class's wait is the sum of its
calls' own durations, and the host issues several calls in one turn that run at once — so those
minutes are not minutes off the clock, and a saving quoted from them against a wall-time figure is
the one misreading this table can produce.

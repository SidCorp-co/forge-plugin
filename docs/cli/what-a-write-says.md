# What a write says

Every route here is one of [one transport](one-transport.md)'s rows; what this holds is the half a
write speaks for itself — the line beside it, and the shape of the answer it hands back.

**A write's answer is what the caller could not already know, and nothing it just sent.** The read
path's list of columns that say nothing to a caller governs the write path too, because a keep-list
is what that list was chosen over and a second one on the write rows would be that refusal taken
back for three routes. On top of it, a field the very same call sent and got back byte-for-byte as
sent is dropped: the process holding the payload learns nothing by reading it again, and on this CLI
that process is an agent paying for it by the token. What the tracker coerced, defaulted or ignored
is precisely what differs from what was sent, so it survives the same test that drops the echo — a
status the move did not land at, a priority the tracker ranked for itself, a field it stored as
null. The comparison is over the JSON text of the two values, which can only ever keep a field it
could have dropped: an object whose keys came back in another order reads as changed and is
answered, where the reverse would be a caller told nothing about a value that moved. The two
identifiers are built above all of it, both of their sources being columns the list drops.

**Announcing a write is not a courtesy owed per verb**, which is how two of them were written without
it. It happens in the transport, so a verb added later cannot forget.

**What it announces is the scope that surprises, once for the command.** A write aimed at the slug
this checkout's own project file names, on a row scoped to a project, with no prose rewrite on the
way out, is the case the caller is already standing in, and a line saying so is a constant: it
trains a reader to skip the place the real sentence appears. What is not the ordinary case still
says itself — the CLI re-aiming the write somewhere else, a row whose subject is a project record
rather than this project, a target that resolved from no source at all, and prose being rewritten
into another language on the way out, which is the target's and not the caller's.

**Once for the command is the unit, because the send is not one.** A verb's round trips are an
implementation detail its caller cannot see: a field write renews the lease before the payload, and
a precondition probe sends one payload twice to discover whether the far end honours a precondition
this process has not yet settled. Neither is a write the caller typed. Counting sends made the line
appear three times for one `advance` and told a reader something true about the transport and
nothing about their issue, so the ledger is kept on the scope rather than on the sentence: the
route that first went there is the one that names it, and every write after it to the same project,
in the same prose, says nothing of its own.

**And the absence of a hold is silence.** The read-before-write gate speaks when it holds a write
back; a line saying it did not hold is a second, weaker statement of the same fact, and the reader
who learns to skip it is the reader who will skip the refusal beside it.
